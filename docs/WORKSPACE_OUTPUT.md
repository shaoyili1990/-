# 任务输出引擎 (workspace/output)

## 一句话
每个任务的结果都同时存 **本地多维表格 + 文件系统**。小白打开 `workspace/output/` 就能看到 AI 干了什么、怎么推理的，不需要会查数据库。

## 目录结构

```
~/workspace/output/
  _README.md              ← 使用说明（可以打开 Obsidian 当知识库）
  T001/                   ← 任务编号
    v1/                   ← 初始版本
      01_问题.md          ← 问题/需求/构思输入
      02_推理过程.md       ← 推理/推导步骤（136子链）
      03_输出结果.md       ← 最终输出
      _迭代说明.md         ← 本次迭代说明（可选）
    v2/                   ← 迭代版本（甲方反馈后修订）
      01_问题.md          ← 新问题（含旧推理+反馈上下文）
      02_推理过程.md       ← 基于新问题重新推理
      03_输出结果.md       ← 修订版输出
  T002/
    ...
```

## 输出模板

输出格式按任务类型决定，规则存在 `output_templates` 多维表格里：

| 任务类型 | 文件数 | 格式 | 适用场景 |
|:---------|:------:|:-----|:---------|
| 创作/分析/推理 | 3 | 01_问题→02_推理过程→03_输出结果 | 小说、分析、逻辑推理 |
| 编程 | 4 | 01_需求→02_设计方案→03_代码实现→04_测试验证 | 编码实现 |
| 研究 | 4 | 01_研究问题→02_方法论→03_发现→04_结论 | 研究分析 |
| **项目** | **4** | **01_思路→02_流程→03_执行方法→04_结果** | **PRD/方案/项目** |
| 默认 | 3 | 三文件制 | 其他 |

## 迭代机制

```
Q1 (初版)                       Q2 (修订版)
  01_问题.txt                    01_问题.txt
  02_推理过程.txt  ──反馈──→     (含旧推理+新反馈)
  03_输出结果.txt                02_推理过程.txt
                                 03_输出结果.txt
```

不是"正确答案"，是"合理性迭代"——甲方说不行，乙方理解反馈，出修订版。这才是真人的拉扯感。

## 核心哲学

- **本地多维表格存核心数据**：迭代、中继、调度全在表格里完成，按需加载 → **物理切割提示词** → 规避幻觉、注意力稀释、上下文过长
- **workspace/output 存直观结果**：让小白能直接看到 AI 的思考过程和输出证据
- **版本不覆盖**：v1→v2→v3 精确回滚，随时可以回头对比
- **双写不冲突**：表格是引擎，文件是窗口

## MCP 工具

通过 MCP 调用工作区工具：

```json
// 初始化
{"method":"workspace_init","params":{"output_root":"~/workspace"}}

// 保存任务输出(三文件制)
{"method":"task_output_save","params":{"task_id":"T001","problem":"...","reasoning":"...","result":"..."}}

// 保存任务输出(PRD四文件制)
{"method":"task_output_save","params":{"task_id":"T001","files_json":"{\"01_思路\":\"...\",\"02_流程\":\"...\",\"03_执行方法\":\"...\",\"04_结果\":\"...\"}"}}

// 迭代: 读取v1全量文件 → 构建新问题(含反馈)
{"method":"task_output_iterate","params":{"task_id":"T001","feedback":"不满意,要改第三点"}}

// 然后AI重新推理,用task_output_save存v2

// 列出所有任务
{"method":"task_output_list","params":{}}

// 读取某版本输出
{"method":"task_output_read","params":{"task_id":"T001","version":"v1"}}
```
