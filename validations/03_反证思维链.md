# 反证思维链通用验证提示词模板

## 1. 验证定义
A为因B为果，求证倒果为因，若B即无法直接倒回A又不存在任何可让B倒回A的其他因素，那么AB无联系。

## 2. 模板定位
所属集合：验证
验证类型：思维路径反证验证

本模板不是普通分析链，不用于继续拆解材料，而用于验证已经生成的分析、推理、结论、方案、聊天回复、提示词输出、项目判断或任何可被逻辑链/思维链拆解的内容是否合格。

可验证对象包括：聊天记录、模型回答、分析报告、提示词、决策方案、逻辑链拆解、思维链拆解、推导过程、因果判断、项目复盘、制度说明、产品方案、论文论证、争议观点等。

## 3. 验证目标
验证待审文本的思考路径是否把“结果 B”错误当作“原因 A”的证明，检查倒果为因、伪相关、伪推理。

验证时不追求“多写分析”，而是判断：
- 是否能通过该验证标准。
- 哪里不通过。
- 为什么不通过。
- 如何修正到可通过。

## 4. 输入要求
用户应提供以下任一内容：
- 待验证文本：{需要审查的回答、方案、分析稿、聊天内容或结论}
- 原始材料：{可选，用于核对事实依据}
- 验证目标：{可选，例如验证逻辑、验证反证、验证是否AI式偷懒}

如果缺少原始材料，只能验证文本内部自洽性；不得假装已完成事实核验。

## 5. 核心验证点
- 是否明确区分 A 是原因、B 是结果。
- 是否错误地用 B 的存在证明 A 必然存在。
- B 是否能直接倒回 A。
- 如果不能直接倒回，是否存在其他因素可合理连接 B 与 A。
- 若连接因素不存在，是否判定 AB 无联系或仅保留弱假设。

## 6. 强制验证流程
1. 抽取所有“A 为因、B 为果”的判断。
2. 检查文本是否发生倒果为因。
3. 尝试从 B 直接倒回 A，记录是否成立。
4. 列出可能让 B 倒回 A 的中介因素、背景因素、主体因素或环境因素。
5. 逐项用材料依据验证这些因素。
6. 若无法倒回且无补充因素，判定 AB 无联系。

【待验证对象】
{粘贴待验证文本、聊天内容、分析稿、结论链路、方案或提示词输出}

【原始材料，可选】

【验证原则】
1. 证据优先：凡是待验证对象声称的事实、因果、逻辑、动机、结论，都必须检查依据。
2. 不替作者脑补：缺证据就是缺证据，不得替文本补全前提。
3. 区分等级：明确标注“通过 / 部分通过 / 不通过 / 无法验证”。
4. 定位问题：必须指出具体问题位置、问题类型、失败原因。
5. 给出修正：每个不通过项都要提供可执行修正方向。
6. 保持通用：聊天内容、普通回答、项目方案、复杂论文、链式分析都可验证。

【强制验证流程】
1. 抽取所有“A 为因、B 为果”的判断。
2. 检查文本是否发生倒果为因。
3. 尝试从 B 直接倒回 A，记录是否成立。

5. 逐项用材料依据验证这些因素。
6. 若无法倒回且无补充因素，判定 AB 无联系。
