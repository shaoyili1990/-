# 反证逻辑链通用验证提示词模板

## 1. 验证定义
定 A 推 B，反查 B 推 A；先看主观因素，再看外部因素；内外皆无，反向为臆断孤证，原结果失效。

## 2. 模板定位
所属集合：验证
验证类型：逻辑关系反证验证

本模板不是普通分析链，不用于继续拆解材料，而用于验证已经生成的分析、推理、结论、方案、聊天回复、提示词输出、项目判断或任何可被逻辑链/思维链拆解的内容是否合格。

可验证对象包括：聊天记录、模型回答、分析报告、提示词、决策方案、逻辑链拆解、思维链拆解、推导过程、因果判断、项目复盘、制度说明、产品方案、论文论证、争议观点等。

## 3. 验证目标
验证待审文本中的逻辑关系是否经得起反向检验，尤其检查“A 能推出 B”是否被误写成“B 必然证明 A”。

验证时不追求“多写分析”，而是判断：
- 是否能通过该验证标准。
- 哪里不通过。
- 为什么不通过。
- 如何修正到可通过。

## 4. 输入要求
用户应提供以下任一内容：
- 待验证文本：{需要审查的回答、方案、分析稿、聊天内容或结论}
- 原始材料：{可选，用于核对事实依据}
- 验证目标：{可选，例如验证逻辑、验证反证、验证是否AI式偷懒}

如果缺少原始材料，只能验证文本内部自洽性；不得假装已完成事实核验。

## 5. 核心验证点
- 是否明确给出了 A 与 B，而不是含混表达。
- A 推 B 的正向关系是否有材料依据或规则依据。
- B 是否能反查回 A；如果不能，是否存在主观因素或外部因素补足。
- 是否把孤立结果、巧合、相关性误判为逻辑证明。
- 内外因素皆无时，是否判定原结论失效。

## 6. 强制验证流程
1. 抽取待验证对象中的 A、B 与声称关系。
2. 验证 A -> B 的正向推理是否成立。
3. 反查 B -> A 是否成立，或是否只能说明“可能有关”。
4. 先检查主观因素：动机、意图、认知、选择、偏好是否能连接 B 与 A。
5. 再检查外部因素：环境、制度、条件、资源、时间、约束是否能连接 B 与 A。
6. 若主观与外部因素都不能连接，则判定该逻辑为臆断孤证。

```text

【待验证对象】
{粘贴待验证文本、聊天内容、分析稿、结论链路、方案或提示词输出}

【原始材料，可选】
{如果有原始材料，请粘贴；如果没有，请明确写“无原始材料，仅做内部自洽验证”}

【验证原则】
1. 证据优先：凡是待验证对象声称的事实、因果、逻辑、动机、结论，都必须检查依据。
2. 不替作者脑补：缺证据就是缺证据，不得替文本补全前提。
3. 区分等级：明确标注“通过 / 部分通过 / 不通过 / 无法验证”。
4. 定位问题：必须指出具体问题位置、问题类型、失败原因。
5. 给出修正：每个不通过项都要提供可执行修正方向。
6. 保持通用：聊天内容、普通回答、项目方案、复杂论文、链式分析都可验证。

【强制验证流程】
1. 抽取待验证对象中的 A、B 与声称关系。
2. 验证 A -> B 的正向推理是否成立。
3. 反查 B -> A 是否成立，或是否只能说明“可能有关”。
4. 先检查主观因素：动机、意图、认知、选择、偏好是否能连接 B 与 A。
5. 再检查外部因素：环境、制度、条件、资源、时间、约束是否能连接 B 与 A。
6. 若主观与外部因素都不能连接，则判定该逻辑为臆断孤证。
```

## 8. 修正策略
- 把确定性结论降级为“可能”。
- 补充能连接 B 与 A 的主观或外部依据。
- 删除孤证推断，改写为待验证假设。
