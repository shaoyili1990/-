## 核心理念：解析解

> **解析解（Analytic Solution）**— 弼马温的核心哲学。
> 
> 一切AI决策使用可能性/倾向性/合理性表述，严格禁止二元判定、数值评分和模板化输出。
> 
> 我们的推理不靠概率拟合，不靠黑盒打分，而是通过136条因果/逻辑/思维/推导子链，输出有依据、可追溯的解析解。

- **离线优先**: 本地化运行，零token消耗冷启动，数据主权归用户
- **多维表格=本体**: SQLite表存储一切，表即Agent的大脑
- **中英双语**: 内部中文推理，结果支持多语言输出

## 防御体系

### Keeper 权限监督
- 29条权限表控制所有角色操作
- 14条宪法硬编码框架规则
- 二元判断关键词前置检测
- 状态机9步流转全链路追踪

### 哈希自愈 + 标准副本
- 哈希自愈引擎：每次执行后自动扫描所有输出文档
- 标准副本守护：8核心表一致性自愈
- error_memories：篡改/异常/越权全记录

## 推理体系 — 136子链 + 10领域指纹

```
4脑 × 34链 = 136条原子推理算子

因果链(34)  一因一果→一因多果→多因一果→直接诱因→深层因果...
逻辑链(31)  主次→互补→因果→传承→依存→互斥→取舍→拆分→时序...
思维链(33)  主次优先级→正反权衡→类比对照→分层拆解→演化推演...
推导法(35)  二分判定→要素考量→条件筛选→动态评估→收敛排除...
```

每个指纹含 **102~134 条** 活跃子链权重 + Tier分级(T1-T5)：
- ACADEMIC(134) / TECH(134) / PRODUCT(134) / BUSINESS(134) / FINANCE(134)
- POLICY(134) / AUTHOR(127) / CRITIQUE(124) / CHAOS(102) / thinker(134)

## 验证体系 — 5条验证链

| 链 | 功能 |
|:---|:-----|
| ① 反证逻辑链 | 逻辑关系反证验证 |
| ② 反AI逻辑链 | 反AI式逻辑错误检测 |
| ③ 反证思维链 | 因果路径反证 |
| ④ 逆AI思维链 | 反AI式思维过程检测 |
| **⑤ 禁止数值解链** | **禁止数值评分/二元标签/模板化输出** |

## 天道系统 — 叙事引擎（`harness_core/tiandao/`）

弼马温的天道系统是小说人物Y值驱动的情绪/欲望演化引擎：
- `tiandao_bridge.py` — 状态机↔天道联动接口
- `y_engine.py` — Y值计算引擎（公式01-10链）
- `harness.py` — 双通道Harness：子链通道（逻辑）+ 天道通道（情绪）

## 快速开始

```bash
git clone https://github.com/shaoyili1990/-.git
pip install -e .
# 编辑 config.yaml 配置API key
# 启动
python3 -m harness_core cold_boot    # 冷启动（零token）
python3 local_cli.py                  # CLI模式
python3 -m harness_core.mcp_server   # MCP服务器
```
